# WeDash

Painel de gestão para redes de franquias — vendas, metas, equipe e comissão.

Stack: **React 19**, **TypeScript**, **Tailwind CSS v4**, **Vite**, **React Router 7**, **Supabase Auth**.

## Quick start

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build → dist/
npm run preview  # preview the production build
```

Copie `.env.example` para `.env` e preencha as chaves do Supabase (ver `supabase/README.md`).
