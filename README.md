# Vela — React Admin Dashboard Template

A premium admin dashboard template built with **React 19**, **TypeScript**, **Tailwind CSS v4**, **Vite**, and **React Router 7**.

- 10 complete demo dashboards (Analytics, CRM, Ecommerce, Finance, Sales, Marketing, Logistics, Projects, SaaS, BI)
- 180+ production-ready pages
- 60+ handcrafted UI components, dependency-free SVG charts
- Dark & light themes, fully responsive, no tracking scripts

## Quick start

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build → dist/
npm run preview  # preview the production build
```

## Documentation

Full documentation — installation, project structure, theming, routing, state management, deployment, and third-party licenses — is included in the `documentation` folder at the root of this package. Open it in any browser.
